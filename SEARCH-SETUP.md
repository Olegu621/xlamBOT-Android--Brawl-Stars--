# Подключение поисковых систем — для владельца сайта

Сайт: https://olegu621.github.io/xlamBOT-Android--Brawl-Stars--/

Карта сайта: https://olegu621.github.io/xlamBOT-Android--Brawl-Stars--/sitemap.xml

## Google Search Console

1. Открой https://search.google.com/search-console/ под своим Google-аккаунтом.
2. Добавь ресурс **«Префикс URL»**, указав полный адрес сайта выше.
3. Для подтверждения выбери **HTML-тег**. Его `google-site-verification` нужно добавить в `<head>` главной страницы, затем опубликовать сайт. Проверочный тег не является паролем; не передавай токены авторизации Google.
4. После публикации нажми «Подтвердить». В разделе Sitemaps отправь адрес карты сайта.
5. В проверке URL укажи главную страницу и запроси индексирование. Аналогично можно проверить страницы `/install/`, `/help/`, `/features/` и `/en/`.

Тег, предоставленный владельцем, размещён в `<head>` главной страницы. Владелец должен завершить подтверждение кнопкой «Подтвердить» в своём Google-аккаунте, затем отправить sitemap. Наличие тега, карты сайта и запрос обхода не гарантируют включение в выдачу или определённое место.

## Другие поисковые системы

Для IndexNow подготовлен файл подтверждения `docs/indexnow.txt` и отправка пяти опубликованных страниц через `python tools/notify_search.py`. Скрипт сначала проверяет, что файл уже доступен по публичному адресу, и отправляет URL только внутри пути этого проектного сайта. Участники IndexNow обмениваются полученными адресами. Это уведомление о страницах, а не гарантия индексации; Google Search Console подключается отдельно.

Тот же сайт и sitemap можно добавить в Яндекс Вебмастер и Bing Webmaster Tools для статистики после подтверждения владения. Используй только проверочные коды своих аккаунтов. [Документация IndexNow](https://www.indexnow.org/documentation).

## Особенности GitHub Pages

`robots.txt` действует на уровне корня домена. Файл внутри адреса проектного сайта не заменяет `https://olegu621.github.io/robots.txt`. Для этого сайта важны доступные HTML-страницы, внутренние ссылки, корректные canonical и карта сайта, отправленная через кабинет поисковика. Отсутствие корневого robots.txt само по себе не запрещает обход.

Поиск GitHub ищет репозитории по имени, описанию, темам и README. Сам сайт GitHub Pages отдельно в поиск репозиториев не входит. Поэтому поддерживаются двуязычное описание проекта, README и тематические метки.

Не создавай фиктивные звёзды, отзывы, форки, посещения или массовые ссылки. Обновления, полезная документация и воспроизводимые отчёты помогают людям оценить проект.

Документация: [Google — запросить повторный обход](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl), [GitHub — поиск репозиториев](https://docs.github.com/en/search-github/searching-on-github/searching-for-repositories).
