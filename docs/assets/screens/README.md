# Actual xlamBOT screen captures

These are optimized WebP copies of real screenshots retained during development and gameplay checks. UI snapshots are from different app versions; the landing page states this beside the gallery. They are not synthetic product renders or testimonials.

- `battle.webp`: active Brawl Stars session with xlamBOT's floating controls, version 1.1.0.
- `panel.webp`: main Android panel, version 1.0.16.
- `brawler.webp`: Larrylawrie search in the brawler picker, version 1.0.14.
- `plus.webp`: Telegram linking / refresh controls, version 1.1.5, before activation.
- `power-boxes.webp`: gameplay with a visible power-up box and health bar.
- `pins.webp`: gameplay with the pin menu open. A still image does not establish who opened it; the caption makes that distinction.
- `phone.webp`: portrait layout and preparation controls, version 1.0.8.

Only image compression was applied. Performance, trophy totals and UI version labels in the images were not altered. Visible bot FPS values refer to analysis throughput, not the game's rendering rate. No screenshot establishes a win rate or guarantees a gameplay result.

## Current 1.2 interface
