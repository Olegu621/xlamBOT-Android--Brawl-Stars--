Стоит на месте, не атакует или unknown

  1. Установи последнюю версию APK поверх текущей. Выключи и снова включи службу xlamBOT в специальных возможностях.
  2. Проверь, что в игре выбран English, в xlamBOT указан правильный боец, а кнопки управления стоят на стандартных местах.
  3. Для проверки выбери Trio Showdown, закрой большую панель xlamBOT и оставь игру видимой.
  4. Открой журнал: если там нет свежих кадров, сначала восстанови изображение по инструкции ниже. Если кадры есть, запиши экран со статусом и последние строки журнала.

Unknown означает, что текущий экран не был уверенно распознан. Само это слово не объясняет причину — важны кадр игры и журнал рядом с моментом остановки.

no_frame, чёрный экран или «Ожидаю изображение»

Останови бота. В Настройках → Получение изображения отключи текущий источник и подключи заново. Для Android 11+ начни с автоматического режима или снимков через специальные возможности. На Android 8–10 подтверди системную трансляцию.

Если выбрано «Одно приложение», убедись, что выбрал именно Brawl Stars и его окно видно. При скрытии выбранного приложения кадр очищается. Подробнее об источниках изображения →

Connection lost и кнопка RETRY LOGIN

В 1.1.2 добавлена отдельная проверка окна Connection lost → Please try logging in again! → RETRY LOGIN. Бот ищет текст кнопки и нажимает её внутри игрового диалога; исчезнувшая кнопка повторно не нажимается.

Обновись и переподключи службу специальных возможностей. Если окно появляется вновь, проверь соединение с игрой. Повторное нажатие не устраняет недоступность серверов. Если бот не нажимает — приложи скрин окна и журнал.

«Пакет недействителен» или приложение не установлено

Удали только недокачанный файл APK из загрузок и скачай его заново с сайта. Проверь свободное место и разрешение на установку у браузера. Нужен Android 8 или новее.

Если версия уже установлена, попробуй поставить новый APK поверх неё. Не удаляй само приложение без сохранения нужных настроек и истории. При повторении пришли точный текст системной ошибки и модель устройства.

«Доступ для приложения запрещён»

Это системное ограничение Android для некоторых установленных вручную приложений. Открой Настройки телефона → Приложения → xlamBOT → ⋮ → Разрешить ограниченные настройки, затем вернись в специальные возможности. Путь может отличаться в оболочке. Пошаговая инструкция →
