Как проверить свой телефон за один полный цикл

  1. Выбери одного бойца, тот же режим и обычные кнопки. Запусти бота из лобби.
  2. В бою отдельно проверь движение и атаку по видимому противнику.
  3. Дождись результата и следующего матча. Для очереди дождись смены бойца по её условию.
  4. Нажми Стоп и убедись, что действия прекратились.
  5. В отчёте укажи модель, Android и оболочку, версию xlamBOT, источник изображения, бойца, режим и результат этих шагов.

Если всё работает, такой отчёт тоже полезен. Отправь его в GitHub Issues или комментарии @xlamModz. При проблеме добавь короткое видео и последние строки журнала, скрыв личные данные.
