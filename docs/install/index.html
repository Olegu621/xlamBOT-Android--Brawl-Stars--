Как установить xlamBOT на Android

От скачивания APK до первого матча. Всё на телефоне, без root и постоянно подключённого компьютера.

1. Скачай и установи APK

Скачивай xlamBOT с этого сайта или из Releases нашего GitHub. Открой файл на телефоне. Если Android попросит, разреши установку для того браузера или файлового менеджера, из которого открыт APK.

При обновлении устанавливай APK поверх предыдущей версии. Удалять приложение для обычного обновления не нужно: удаление может стереть локальные настройки, очередь и историю.

2. Включи управление касаниями

В xlamBOT открой подготовку и включи службу xlamBOT в специальных возможностях. Она нужна для нажатий и движения. Также разреши окно поверх игры, чтобы видеть плавающую панель запуска и остановки.

Android пишет «Доступ для приложения запрещён»?

  1. Открой системные Настройки → Приложения → xlamBOT.
  2. В меню ⋮ найди «Разрешить ограниченные настройки» и подтверди действие. На разных прошивках название и расположение отличаются.
  3. Вернись в специальные возможности и включи службу xlamBOT.

Делай это только для APK, который сам скачал из нашего репозитория. Справка Android об ограниченных настройках ↗

3. Подключи изображение игры

Открой Настройки xlamBOT → Получение изображения. Изображение анализируется на устройстве.

  • Android 11 и новее: доступны снимки через специальные возможности, без запроса трансляции.
  • Android 8–10: выбери системную трансляцию и подтверди разрешение захвата экрана.
  • Android 14 и новее: при выборе трансляции поддерживаемая прошивка предлагает «Одно приложение». Выбери Brawl Stars. Для появления выбора отключи старый источник и подключи его заново.
Выбранное окно игры должно быть видно. Захват отдельного приложения не добавляет игру в фоне или с заблокированным экраном.

4. Проверь первый матч

  1. Для первого запуска поставь English в игре, обычное расположение кнопок и Trio Showdown.
  2. Выбери в xlamBOT того бойца, который сейчас открыт в игре, и один из трёх стилей.
  3. Открой обычный Brawl Stars и нажми запуск на плавающей панели. Оставь игру на экране.
  4. Проверь движение, атаки и переход к следующему матчу. Если бот стоит, открой журнал и посмотри строку состояния.

Чтобы убрать плавающую панель, используй кнопку «Закрыть» в панели xlamBOT. Для настройки нескольких бойцов используй «Мою очередь»; смена после чистого прироста +N кубков в 1.2 доступна бесплатно во вкладке «Очередь».

Как обновляться

Новые APK устанавливаются вручную с сайта. После обновления выключи и снова включи службу xlamBOT в специальных возможностях. Если источник изображения перестал отвечать, отключи и подключи его заново.
